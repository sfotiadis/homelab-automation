# Homelab Infrastructure Automation

Infrastructure as Code (IaC) for my homelab environment running on Proxmox VE.

> **Workload Management:** This repository handles infrastructure setup. Application deployments are managed via GitOps in [homelab-gitops](https://github.com/sfotiadis/homelab-gitops).

## Overview

This repository automates the complete deployment and management of my homelab infrastructure:

- **VM Templates**: Built with Packer (Ubuntu 24.04 Cloud-Init ready)
- **Infrastructure Provisioning**: Managed with Terraform (Proxmox VMs)
- **Configuration Management**: Automated with Ansible (DNS, K8s, LoadBalancer)

Core infrastructure includes DNS servers, a Kubernetes cluster, load balancing with HAProxy, and everything needed for a production-grade self-hosted environment.


## Architecture

### Infrastructure Components

| Component | Count | Specs | Purpose | VM IDs |
|-----------|-------|-------|---------|--------|
| DNS Servers (BIND9) | 2 | 2 vCPU, 2GB RAM, 20GB | Primary/Secondary DNS with dynamic updates | 201-202 |
| HAProxy LoadBalancer | 1 | 2 vCPU, 4GB RAM, 30GB | K8s API + HTTP/HTTPS Ingress LB | 305 |
| K8s Control Plane | 3 | 4 vCPU, 8GB RAM, 50GB | HA Kubernetes control plane | 301-303 |
| K8s Worker Nodes | 3 | 8 vCPU, 20GB RAM, 100GB | Application workloads | 311-313 |

**Total Resources:** 9 VMs | 42 vCPUs | 92 GB RAM | 520 GB Storage
